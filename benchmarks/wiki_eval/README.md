# معيار ويكيبيديا المستقل — wiki_eval

معيار تحقق مستقل بالكامل لقدرة المكتبة على استرجاع النص العربي من PDF:
**الحقيقة الأرضية معروفة لأننا أنشأناها** — مقالات ويكيبيديا منظفة ← PDF ←
استخراج وإصلاح ← مقارنة بالمصدر المنظف.

## البنية

```
articles.json      قائمة 14 مقالة من مجالات متنوعة + سياسة الذهب
fetch_articles.py  جلب API ويكيبيديا + تنظيف → articles/<slug>.gold.txt
make_pdfs.py       توليد pdfs/<slug>.<mode>.pdf بثلاثة أنماط تخزين
run_eval.py        الحلقة: خام + إصلاح + CER/WER + تصنيف سببي + مراقبة داخلية
drilldown.py       تشريح خطأٍ بعينه بسياقه وسببه المرجح
compare_marks.py   مقارنة اتفاقية ربط الحركات (forward_flank_marks)
reports/           eval_report.json — النتائج الكاملة
```

## أنماط التخزين الثلاثة ودلالتها الفعلية

⚠️ **الدلالة تقاس بمخرَج مستخرج الأنبوب لا بأداة قراءة خارجية** — اكتُشف
أن `fitz.get_text()` يطبّق تصحيح bidi داخلياً بينما `PyMuPDFExtractor`
(المسار الهندسي الذي يستعمله الأنبوب) يعيد الجليفات بترتيبها المواقعي:

| النمط | ما يُخزَّن في PDF | ما يراه الأنبوب | مسار الإصلاح |
|---|---|---|---|
| `clean` | يونيكود منطقي بحروف أساسية | **معكوس بالكامل** (برهان وصل: 1061/1761 خرقاً) | عكس فقط |
| `pf` | أشكال رسومية منطقية | أشكال رسومية معكوسة | تطبيع + عكس |
| `pf_visual` | أشكال رسومية بصرية | أشكال رسومية منطقية | تطبيع فقط |

## نتائج مختصرة (42 ملفاً)

* الخام قبل الإصلاح: CER ‏73%–93% — بعد الإصلاح: **0.1%–4.9%**
* أفضل حالة: human-rights ‏**0.05%–0.3%** عبر الأنماط الثلاثة
* pf_visual (أسهل فئة): غالباً **< 1%**

## الاكتشافات الجوهرية التي أنتجها المعيار

1. **فخ `arabic_reshaper`**: إعداده الافتراضي يحذف الحركات
   (`delete_harakat=True`) — دمّر التشكيل قبل دخوله PDF وألقى باللائمة
   ظلماً على المكتبة. عولج في المولّد (`delete_harakat=False`)، وأثبت
   عزل المراحل أن arafix يحفظ الحركات 511/511.
2. **ازدواجية واقع الاستخراج**: نفس الـPDF يعطي نصاً منطقياً من
   `fitz.get_text()` ومعكوساً من المسار الهندسي — أي قياسٍ لا يمر عبر
   مسار المستخرج الفعلي يقيس شيئاً آخر.
3. **اتفاقية ربط الحركات خاصيةُ المولِّد**: ثبوت الانعكاس (برهان الوصل)
   لا يثبت الاتفاقية. ملفات مُشكَّلة قديمة تنتج انعكاساً خاماً
   (الحركة قبل قاعدتها)، وملفات رقمية حديثة تحافظ على العناقيد —
   والربط الأمامي يصلح الأولى ويفسد الثانية (قياساً: ‎12.5%←‎<3% هنا،
   مقابل ‎2%←‎11.6% هناك). لذلك `forward_flank_marks` علمٌ صريح
   opt-in لا استنتاج تلقائي.
4. **فجوة مشروعة**: حروف القبطية (ⲫⲓⲁⲣⲟ) تسقط في nile — نطاقٌ خارج
   نطاقات العربية الحالية، موثَّق كحدٍّ معروف.

## إعادة التشغيل

```bash
python fetch_articles.py     # --force لإعادة الجلب
python make_pdfs.py
python run_eval.py           # التقارير في reports/
python drilldown.py <slug> <mode>   # تشريح خطأ بعينه
python compare_marks.py      # أثر اتفاقية العلامات
```
