# ميدان Glyph Evidence المُعنون — glyph_fixtures

مدونة مرجعية مُعنونة تربط الجليفات «المكذوبة» بحروفها الحقيقية، وتفتح
الباب أمام تفعيل طبقة Glyph Evidence بأمانٍ (بدون رفع FPR). هذا يعالج
الحالة التي كان المستودع يمتنع فيها صراحةً: لا fixture معلن يربط محرفاً
خاطئاً في طبقة النص بشكله الصحيح في الخط المضمّن.

## الحالات الـ13 (v2 — عقد arafix.glyph-fixture.v2)

تغطي عائلات النقاط والهمزات كاملة، كل حالة بوثيقة مستقلة:

| العائلة | الحالات (الحقيقة→الكذبة) |
|---|---|
| الرسومية/المربوطة | ه→ة · ي→ى |
| أحادية النقطة | د→ذ · ر→ز |
| ثنائية النقطة | ب→ت |
| ثلاثية النقاط | خ→ح (من ج/ح/خ) |
| ص/ض | ض→ص |
| ط/ظ | ظ→ط |
| س/ش | ش→س |
| ع/غ | غ→ع |
| الهمزات | ؤ→و · ئ→ي · أ→ا |

كل حالة: PDF فُسدت ToUnicode فيه عمداً، بخط **Amiri-Regular** (SIL OFL
1.1 — آمنة لإعادة التوزيع)، وصفحات ضوابط FPR حقيقية (حرف الكذبة أصلاً:
الشهادة · على · الذهب · الزيتون · التاريخ · الحقيقة · أساس · الطاولة ·
السماء · العربية · الورود · الماء · الوفاء)، والذهب يسجل cids المفسودة
وصفحات الهدف والسياق.

## المعايرة الموثقة للدمج

`Confusion(lie, true, cost=0.50)` — **حيادٌ مقصود**: جسرُ الالتباس لا
رأيَ له، والسلطة لدليل الجليف وحده. عند cost أدنى (0.30 جرّبناها)
يطفو مرشحُ الالتباس المتناثر فوق المرشح الكثيفِ المُثقلِ بأصفارٍ
مشروعة فينهار هامش القرار (قيس: 0.700 مقابل 0.703). الحيادي 0.50
يرتب المرشحين ترتيباً موثوقاً ويبقي بوابة الاستقلالية هي الحَكَم.

## حدود موثَّقة

* **الخطوط المقصوصة خارج النطاق حتى الآن** (`doc.subset_fonts()` يقصم
  أسماء الجليفات ويحذف جدول cmap بالكامل — قِيس تجريبياً: لا أسماء ولا
  cmap، لم يبقَ إلا مخططات الرسم). مسارها الوحيد `shape_match`
  (تصميمه مشار إليه في cmap.py، غير منفَّذ بعد).
* **الكلمة متعددة المواضع** («جديد»←«جذيذ»: تبديلان لنفس الزوج) خارج
  نطاق الدمج العام: معجم السياق يقصر على مسافة تحرير 1 ونموذج الالتباس
  يستبدل موضعاً واحداً لكل مرشح، فلا يصل المرشح إلا بدليل جليفٍ منفرد
  ويمتنع. فلتر المحاذاة يعكس هذا الحدّ عمداً — ولذلك تختار مدوناتنا
  كلمات هدفٍ أحادية الحرف.
* الفساد الحالي أساسي-محارف؛ امتداد الصيغ الرسومية ككذباتٍ ممكنٌ عبر
  نفس الآلية.
* الوثائق ترسم الصيغة المعزولة فقط؛ بقية صيغ الزوج مفسودةٌ في ToUnicode
  لكنها غير مرسومة — بوابة الكشف تحكم على المرسوم (وتسجّله الذهب).

## إعادة التشغيل

```bash
python benchmarks/glyph_fixtures/make_fixtures.py        # توليد الحالات + الذهب v2
python benchmarks/glyph_fixtures/verify_glyph_signal.py  # بوابة الإشارة ×13
python benchmarks/glyph_fixtures/fusion_gate.py          # بوابة الدمج ×13
pytest tests/hardening/test_h14_glyph_fixtures.py -q     # التثبيتات ×39
```

يتطلب الإضافة `[pdf]`: `pip install "arafix[pdf]"`.
