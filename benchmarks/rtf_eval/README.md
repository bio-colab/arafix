# RTF evaluation fixture

هذا الملف هو مستند RTF عربي اختير عشوائياً لأغراض الفحص، ثم نُزّل من **المكتبة الشاملة** وحُوّل محلياً إلى PDF قبل تشغيل استخراج النص. لا يعتمد الإصلاح على كلمات هذا الملف؛ استُخدم فقط كمرجع قياس مستقل.

| الحقل | القيمة |
|---|---|
| الملف | `الشاء.rtf` |
| نوع الاختبار | تحويل محلي إلى PDF ثم استخراج النص العربي |
| عدد صفحات PDF الناتج | 8 |
| SHA-256 لملف RTF | `d2b15b7264f743905b6dd2e2242be3a5d1c40fbd3112358b42b03b3efbfac16e` |
| نص المرجع | `../../../../rtf_pdf_eval/gold/rtf_reference.txt` في بيئة القياس الأصلية |

## طبيعة التعديلات

شملت التغييرات تعديلات ذرية عامة، منها حماية النصوص اللاتينية والمعرّفات من الإصلاح الزائد، تضييق إصلاحات المسافات داخل الكلمات والالتباسات الشائعة في مخرجات PDF، تحسين إعادة بناء glyphs العربية عند وجود ترتيب هندسي لام/ألف، وتمرير إعدادات layout من pipeline إلى المستخرج مع تقليل إعادة بناء layout وإعادة تشغيل مراحل الإصلاح كاملةً.

كما أضيف cache لنصوص الأسطر وتحسين حساب فواصل الأعمدة، مع تحديث التشخيص وaudit بعد التغييرات المتأخرة. بقي الإصدار المعلن للمكتبة **1.0.1**.
