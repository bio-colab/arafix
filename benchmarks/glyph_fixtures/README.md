# ميدان Glyph Evidence المُعنون — glyph_fixtures

مجموعة مرجعية مُعنونة تربط الجليفات «المكذوبة» بحروفها الحقيقية، وتفتح
الباب أمام تفعيل طبقة Glyph Evidence بأمانٍ (بدون رفع FPR). هذا يعالج
الحالة التي كان المستودع يمتنع فيها صراحةً: لا fixture معلن يربط محرفاً
خاطئاً في طبقة النص بشكله الصحيح في الخط المضمّن.

## ما الذي يبنيه؟

`make_fixtures.py` يولّد PDF طبقةُ `ToUnicode` فيه مفسودةٌ عمداً: كل
جليف حقيقتُه «ه» يُبلَّغ عنه بـ«ة»، بينما يحفظ الخط المضمّن نفسه
(**Amiri-Regular**، رخصة SIL OFL 1.1 — آمنة لإعادة التوزيع) الحقيقة في
جدول cmap وأسماء الجليفات. الذهب `assets/gold_manifest.json` يسجّل:

* cids المفسودة وحقيقتها (`arafix.glyph-fixture.v1`)
* نصوص الصفحة الهدف وصفحات السياق النظيف

## البوابات الثلاث

| السكربت | ماذا يثبت؟ | البوابة |
|---|---|---|
| `verify_glyph_signal.py` | كشف التناقض حتمي: كل جليف مرسومٍ حقيقتُه «ه» ضُبط، وصفر تناقض خارج الذهب | خروج 1 عند أي فوت أو تناقض زائف |
| `fusion_gate.py` | الاسترجاع عبر **الواجهة العامة فقط** (`GlyphEvidence` + `DocumentContext` + `EvidenceFusion`) بنسبة RAR=100% حرفياً | خروج 1 على أي إصلاح كاذب أو فائت |
| `tests/hardening/test_h14_glyph_fixtures.py` | تثبيت الأعلاه + تثبيت تحفظ الأنبوب الحالي (لا إصلاح تلقائي لكذبات المحارف العادية) | pytest |

نتائج اليوم: تناقض واحد بالضبط (gid ﻩ المعزولة) مقابل ذهبٍ من 4 cids
(الأربع صيغ مفسودة والوثيقة ترسم واحدة)، واسترجاع حرفي ‏7/7 كلمات بصفر
إصلاح كاذب.

## حدود موثقة (للتوسع لاحقاً)

* الفساد الحالي زوج واحد (هـ/ة) — التوسع إلى ي/ى وك/… مسارٌ مباشر عبر
  `PAIR`.
* الوثيقة ترسم الصيغة المعزولة فقط؛ الصيغ الأخرى مفسودةٌ في ToUnicode
  لكنها غير مرسومة — بوابة الكشف تحكم على المرسوم.
* دليل الجليف هنا من أسماء/جدول الخط (glyph_names)؛ الخطوط subsets
  بلا أسماء تحتاج مسار shape_match (غير مفعّل عمداً).

## إعادة التشغيل

```bash
python benchmarks/glyph_fixtures/make_fixtures.py        # توليد + ذهب
python benchmarks/glyph_fixtures/verify_glyph_signal.py  # بوابة الإشارة
python benchmarks/glyph_fixtures/fusion_gate.py          # بوابة الدمج
pytest tests/hardening/test_h14_glyph_fixtures.py -q     # التثبيتات
```

يتطلب الإضافة `[pdf]`: `pip install "arafix[pdf]"`.
