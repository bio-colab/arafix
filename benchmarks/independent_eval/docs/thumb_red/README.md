# كتاب الفحص الذهبي: بصمة الإبهام الحمراء

**Canonical regression book** for arafix quality work.

| | |
|--|--|
| **المصدر** | [صفحات / safahat.org](https://www.safahat.org/) — PDF منشور مسبقًا |
| **ليس** | مولَّد بالذكاء الاصطناعي، ولا من تأليف مطوّري arafix |
| **الملف** | `source.pdf` (محلي؛ gitignored) |
| **الـ gold** | 5 صفحات مراجعة يدويًا في `sample/page_*_gold.txt` |

## لماذا هذا الكتاب؟

1. نص عربي أصلي كثيف (رواية مترجمة / سرد) مع Presentation Forms.
2. diglossia of defects: مسافات مفقودة، `امل`/`الم`، ي/ن، ي/ر، بقايا `هذالا`.
3. حجم متوسط (~200 صفحة) يسمح باستخراج كامل دون أن يكون غير عملي.

## الحلقة: استخرج → قِس → أصلح الجذر → أعد

```bash
# من جذر المستودع
python benchmarks/independent_eval/eval_thumb_red.py --refresh
# التقرير: benchmarks/independent_eval/thumb_red_eval.json
```

## جذور أُصلحت

**حلقة 1:** `امل`+تشكيل، `هذالا`، `روبني`/`حين`…  
**حلقة 2:** percentile + `collapse_midword_spaces`  
**حلقة 3:** q=0.72، طيّ أوسع، `insert_particle_spaces` محافظ، confusions إضافية  

## جذور ما زالت مفتوحة (حلقة 4+)

1. WER نحو 0.5 (ما زال ~0.80).  
2. ترويسة `راسرأ` (ترتيب جليفات العنوان في PDF وليس عكسًا بسيطًا).  
3. تشكيل (`عرٍض`) وي/ن (`طني`/`طين`، `محلفني`/`محلفين` المتبقية).

## الشفافية

كل رقم في `thumb_red_eval.json` و`pilot_eval.json` مبني على هذا الكتاب المنشور + gold يدوي — صالح للعرض على مراجع أكاديمي كـ held-out evaluation، لا كـ unit test مولَّد.
