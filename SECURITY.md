# Security Policy / سياسة الأمان

## Supported Versions / الإصدارات المدعومة

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability / الإبلاغ عن ثغرة أمنية

If you discover a security vulnerability or potential attack vector (e.g. malicious PDF font tables or malformed Unicode exploits), please **do not open a public issue**.

Instead, please report the vulnerability privately via:
1. GitHub Security Advisories: [Report a vulnerability](https://github.com/bio-colab/arafix/security/advisories/new)
2. Or contact the maintainers directly via email at `aliasbio95@gmail.com`.

We appreciate your responsible disclosure and will acknowledge receipt within 48 hours and work with you on a timely resolution.
